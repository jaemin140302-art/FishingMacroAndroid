낚시 매크로 - Android 프로젝트 초안

중요:
- 이 ZIP은 APK가 아니라 Android Studio 프로젝트 소스입니다.
- Android Studio와 Android SDK로 빌드해야 설치 가능한 APK가 됩니다.
- 이 실행 환경에서는 APK를 빌드하거나 실제 갤럭시 Z Flip4에서 검증하지 못했습니다.
- 기본 터치 좌표(540,1500 / 540,1000)는 임시값입니다. 기기 해상도와 게임 UI에 맞지 않을 수 있습니다.
- 현재 버전은 PERFECT/입질/낚시 완료를 화면에서 인식하지 않습니다.
- 2초 누르기 -> 5초 대기 -> 15초 탭 반복을 수행하는 기본 프로토타입입니다.
- 게임 업데이트/화면 비율/해상도에 따라 동작이 달라질 수 있습니다.

설치/실행 준비:
1. Android Studio에서 이 폴더를 엽니다.
2. Gradle 동기화를 완료하고 APK를 빌드합니다.
3. 휴대폰에 APK를 설치합니다.
4. 앱에서 '화면 위 표시 권한 설정'을 허용합니다.
5. 접근성 설정에서 '낚시 매크로' 서비스를 켭니다.
6. 앱으로 돌아와 플로팅 아이콘을 띄웁니다.

안전 및 제한:
- 접근성 권한은 강력한 권한입니다. 본인이 신뢰하는 소스의 앱에만 허용하세요.
- 이 앱은 로블록스 내부를 수정하지 않으며, 화면 제스처를 보내는 방식입니다.
- 현재는 좌표 편집 화면과 자동 감지 기능이 없습니다.


휴대폰만으로 온라인 빌드하는 방법:
1. 크롬에서 github.com에 로그인하고 새 저장소(New repository)를 만듭니다.
2. ZIP 압축을 풀고 안의 FishingMacroAndroid 폴더에 있는 파일들을 저장소 최상위에 올립니다.
3. 저장소의 Actions 탭에서 'Build Android APK'를 선택합니다.
4. Run workflow를 누르고 빌드가 끝날 때까지 기다립니다.
5. 실행 기록 아래 Artifacts에서 FishingMacro-debug-apk를 다운로드하고 압축을 풉니다.
6. app-debug.apk를 눌러 설치합니다.

주의: GitHub 계정과 인터넷 연결이 필요합니다. 이 프로젝트는 실제 휴대폰/게임에서 검증되지 않았고 기본 터치 좌표는 임시값입니다. APK 설치 후 화면 위 표시와 접근성 권한을 직접 허용해야 합니다.
